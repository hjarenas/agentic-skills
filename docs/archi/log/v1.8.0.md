# v1.8.0

## 2026-10-02 — Waiting by inactivity, worker dispatch discipline, origin as release ground truth

A month of downstream `crm` runs showed the review gates earning their cost while time and tokens
leaked between them, so `agent-routing.md` now detects a stalled worker by inactivity rather than
a flat wait cap. The same contract keeps one watchdog per flow, bans no-op polling and idle
turn-ends, and gives every dispatch a literal location check, a short report, foreground-only
commands and `BLOCKED` on a denied tool. `TRIP-2-implement` and `TRIP-3-release` replace
`git add -A` with staging by explicit path under one defined clean-tree check, add an
integration-fix commit after the code-review loop, and tick plan checkboxes once per phase gate.
Releases measure against `origin`, commit through `workspace-worker`, and name their artifacts
`w<WEEK>_v<X.Y.Z>`.
