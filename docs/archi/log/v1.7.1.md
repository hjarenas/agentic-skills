# v1.7.1

## 2026-08-24 — TRIP-upgrade path routing split into two axes

`TRIP-upgrade`'s Phase 0 now decides two things independently: one **structural path** (legacy
skills, missing `## Agent routing`, neither, or no structural work left) and a set of **standalone
migrations** that each run whenever their own condition holds, across the legacy, routing and "no
structural work" paths alike. The 1.7.0 backfills — the worktree-bootstrap profile subsection and
the `git worktree` permission allowlist — were reachable only through the structural axis, so a
project already on the plugin model hit an "already current" exit and could never receive them.
That exit survives but now also requires both standalone conditions to be satisfied, and the
"neither exists" row is carved out explicitly so an uninitialized repo still goes to `/TRIP-init`
rather than having settings written into it.
