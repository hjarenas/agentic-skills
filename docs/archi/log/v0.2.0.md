# v0.2.0

## 2026-08-15 — worktree-based flow and phase parallelism

`trip` gained two axes of git-worktree isolation: one worktree per `TRIP-auto` flow (so two flows
never collide on the same working tree), and one worktree per independent plan phase within a
flow (dependency-graph-driven, computed as a frontier, running phase batch loops in parallel and
merging them back one at a time through a serialized merge slot, with in-place conflict
resolution). `codex-bridge` fixed a load-bearing diff-baseline bug in `codex-code-review`
(`git diff HEAD` → `git diff $(git merge-base <main> HEAD)`) that the new mid-flow phase commits
would otherwise have exposed, documented the worktree/merge operations `codex-workspace` may
perform when explicitly allowlisted, and recorded that Codex's `--resume-last` thread tracking is
safely isolated per git worktree.
