## Changes

- **`trip` plugin (1.3.0 → 1.4.0)**: added git-worktree-based parallelism across two axes.
  - **Outer parallelism**: one worktree per TRIP flow, so two `TRIP-auto` runs no longer collide
    on the same working tree.
  - **Inner parallelism**: dependency-graph-driven parallel worktree-isolated batch loops per
    independent plan phase within a single flow, with serialized phase-merge/cleanup so only one
    phase mutates the shared feature worktree at a time, explicit merge-conflict-in-place
    resolution (a conflicted merge is resolved and completed, never aborted and retried), and
    updated failure-handling guarantees that correctly exempt an unresolved-conflict stop state
    from the "clean and pushed" promise.
- **`codex-bridge` plugin (1.2.1 → 1.2.2)**: fixed `codex-code-review`'s diff baseline from
  `git diff HEAD` (which narrows to only the most recent commit once phases commit mid-flow) to
  `git diff $(git merge-base <main> HEAD)`, so a feature-wide review sees the whole feature
  regardless of how many phase commits landed in between. Also documents the new worktree/merge
  operations `codex-workspace` may perform when explicitly allowlisted, and records a finding
  that Codex's `--resume-last` thread tracking is safely isolated per git worktree.
